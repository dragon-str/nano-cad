Why GROMACS cannot run the model
--------------------------------
The nanocad vdW term is Buckingham: U = A exp(-B r) - C / r^6.
The installed GROMACS reports, from `gmx mdrun`:

    The Verlet cutoff-scheme does not (yet) support Buckingham

GROMACS removed the group cutoff scheme in 2020, and Buckingham was only ever
supported with that scheme. Separately, GROMACS 2026 implements only the
potential-shift modifier, not a switching function (the reference manual keeps
the switch formula for a future release). The nanocad custom switching
polynomial therefore has no GROMACS equivalent. A tabulated nonbonded
potential (`vdwtype = User`) is also unavailable with the Verlet scheme in
2026; the GROMACS developers state it returns in the 2027 release.

For these reasons the harness cannot record a measured agreement. It prints
SKIP and exits zero. This is the honest outcome, not a fake comparison.

What the harness does verify
----------------------------
1. `gmx grompp` accepts the exact topology: 200 molecules, 600 atoms, nbfunc 2
   (Buckingham), the same charges, the same harmonic bond and angle, 3 excluded
   intra-molecular pairs per molecule, and the same cubic box and cutoff.
2. The Coulomb constant converts exactly: GROMACS 138.935458 matches nanocad
   138.935458 kJ/mol/nm/e^2 at the printed precision.
3. The switch-correction function is consistent with an independent Python
   evaluation of the reference model: bonded plus switched non-bonded energy
   equals the recorded nanocad energy to 6.75e-15 relative, and the correction
   equals the plain-cutoff minus switched value to machine precision. Reproduce
   with: python3 benchmarks/gromacs/selftest_switch.py
