TASKS.md — The Iterative Backlog

This is the backlog. A coding agent picks the first unchecked task in the current milestone. When the user names a task, do that one.

Work loop: mark the line with &lt;!-- WIP --&gt;, implement with tests, run just verify, then change [ ] to [x] and append a result note.
